## 🧠 How I Engineer
 
| Principle | What it looks like in practice |
|---|---|
| **Correctness first** | State machines, idempotency keys, row-level locks, rollbacks |
| **Failure is normal** | Network partitions, late joiners, partial failures designed for up front |
| **Concurrency with discipline** | Structured concurrency (Trio nurseries), no leaked tasks, deterministic errors |
| **Prove it** | Fixtures, mocking, regression suites — 107 tests and counting |
| **Ship with zero downtime** | Atomic pointer swaps, containerized services, async offloading |
